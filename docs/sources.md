# Official sources

The docs in this folder are **paraphrased, bilingual summaries** written for
this project. They are not copies of official pages, and they are not legal,
tax, or medical advice. Always check the official source before acting,
because rules, deadlines, and fees change.

- SAAQ (driver's licence, vehicle registration): https://saaq.gouv.qc.ca
- RAMQ (health insurance): https://www.ramq.gouv.qc.ca
- Tribunal administratif du logement (housing): https://www.tal.gouv.qc.ca
- Revenu Québec (taxes): https://www.revenuquebec.ca
- Francisation Québec (free French courses): https://www.quebec.ca/education/apprendre-francais
- Place 0-5 ans (childcare waitlist): https://www.place0-5.com
- GAMF / Info-Santé 811 (family doctor, health advice): https://www.quebec.ca/sante
